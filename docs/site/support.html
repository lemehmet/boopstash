Support

Help with installing and using BoopStash.

Install and update

With Homebrew:

brew install --cask lemehmet/boopstash/boopstash
brew upgrade --cask lemehmet/boopstash/boopstash

Or download the .zip from GitHub releases; each release ships a SHA-256 checksum. The app is signed with Developer ID and notarized by Apple. BoopStash needs macOS 26 or newer; on-device titles need Apple Silicon with Apple Intelligence turned on.

Report a problem or ask a question

Open an issue on GitHub. Include your BoopStash version (BoopStash ▸ About BoopStash) and your macOS version. Please don't paste private notes or clipboard contents into a public issue.

Report a security vulnerability privately through GitHub's security advisories, not in a public issue.

Keep a copy of your notes

Choose File ▸ Export All Notes… to write every note as a Markdown file, with its images beside it, into a folder you pick. The files are plain text you can read, search or import elsewhere.
