BoopStash

A scratch pad for macOS that remembers. Paste a snippet, an agent's output or a screenshot, and find it again next week by what it was about, when you copied it, or where it came from.

  • Notes persist. Every note is kept, titled for you on-device, and searchable by title, content and age.
  • The editor stays out of the way. No auto-closing quotes or smart punctuation; key bindings follow VS Code or JetBrains.
  • Images are notes too. Paste a screenshot; its text is recognised on your Mac and becomes searchable.
  • Boop's scripts keep working, and Format Document formats JSON, XML, JavaScript, CSS, YAML, Markdown, SQL and more.

Install

brew install --cask lemehmet/boopstash/boopstash

Or download the signed, notarized .zip from GitHub releases. BoopStash needs macOS 26 or newer.
